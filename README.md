# Время — Валюта

Трекер дневного бюджета времени. Идея: каждое утро ты получаешь фиксированный
запас времени, тратишь его в течение дня, а неиспользованный остаток сгорает
в конце дня — как невозвратный лимит внимания, а не как «потерянное время».

## Запуск

```bash
npm install
npm run dev
```

Открой адрес, который выведет Vite (обычно `http://localhost:5173`).

Сборка для продакшена:

```bash
npm run build
npm run preview
```

## Стек

- React 18 + TypeScript
- Vite
- Tailwind CSS (тёмная/светлая тема через CSS-переменные)
- Recharts (графики на странице «Аналитика»)
- lucide-react (иконки)
- Данные хранятся в `localStorage` — ничего не потеряется при перезагрузке

## Архитектура

```
src/
  types/index.ts        — все доменные типы (Transaction, Category, PlanItem, Settings, ...)
  utils/
    time.ts              — форматирование времени, расчёт «логического дня»
    storage.ts           — тонкий слой поверх localStorage (легко заменить на API)
    defaults.ts          — дефолтные категории/настройки, генератор id
  hooks/
    useTimeStore.tsx      — единственный источник правды: React Context + useReducer,
                            вся бизнес-логика (таймер, сгорание бюджета, CRUD) живёт здесь
  components/
    Dashboard.tsx         — главный экран: кольцевой индикатор, баланс, «куда уйдёт час»
    Wallet.tsx             — «кошелёк времени»: список операций, редактирование/удаление
    AddExpenseModal.tsx    — модалка добавления/редактирования расхода
    Planning.tsx           — план на сегодня, распределение бюджета
    Categories.tsx         — управление категориями (свои + предустановленные)
    Stats.tsx               — аналитика: пироги, бар-чарты по дням, топ утечек, план vs факт
    History.tsx             — календарь + детальный просмотр любого дня
    Settings.tsx             — размер бюджета, время начала дня, тема, авто-трекинг, напоминания
    Notifications.tsx        — простые тосты для напоминаний (во время активности / остаток бюджета)
    DayEndModal.tsx           — экран «День завершён» при переходе через полночь (без осуждения)
    Nav.tsx                    — навигация: сайдбар на десктопе, таб-бар на телефоне
  App.tsx                       — сборка экранов, применение темы
```

### Почему так

- **Один reducer, один источник правды.** Все операции (добавить расход,
  запустить таймер, создать категорию) идут через `useTimeStore`, поэтому
  экран статистики, кошелёк и история всегда согласованы.
- **«Логический день» вместо календарной даты.** День может начинаться не в
  00:00, а, например, в 07:00 (настраивается) — `dayKeyForInstant` учитывает
  это при расчёте, к какому дню относится расход.
- **Сгорание — это просто отсутствие переноса.** Бюджет каждый день
  пересчитывается из `settings.dailyBudgetHours`, старые остатки нигде не
  прибавляются — физически невозможно «накопить» время, как и задумано.
- **Слой `storage.ts` изолирован**, чтобы в будущем заменить `localStorage`
  на реальный backend/аккаунты, не трогая компоненты.
- **Никаких оценочных формулировок.** Тексты сознательно нейтральны: «ты
  потратил», «не было использовано» — нигде нет «ты потерял» или рейтингов.

## Проверенные сценарии

1. Открытие утром → баланс = `dailyBudgetHours`, кошелёк пуст.
2. Дневной бюджет виден на дашборде и в настройках (регулируется слайдером).
3. Добавление расхода вручную — модалка → кошелёк → баланс уменьшается.
4. Запуск таймера — кнопка в блоке «Куда уйдёт следующий час».
5. Остановка таймера — создаёт транзакцию с реальной длительностью.
6. Баланс и кольцо обновляются раз в секунду, пока таймер активен.
7. Статистика — переключатель «Сегодня / 7 дней / 30 дней», графики и топ утечек.
8. История — календарь, клик по дню показывает разбивку операций.
9. Наступление нового дня — при следующем открытии/пересечении полуночи
   показывается модалка «День завершён» с итогами, затем бюджет обнуляется.
10. Все данные (транзакции, категории, план, настройки, напоминания)
    сохраняются в `localStorage` и восстанавливаются при перезагрузке страницы.

## Известные ограничения этой версии

- Напоминания реализованы как in-app тосты (без браузерных Push-уведомлений
  и без фонового трекинга, когда вкладка закрыта) — это самый безопасный
  вариант для чистого frontend без бэкенда.
- «Напоминание за N минут до начала» пока не привязано к конкретному
  запланированному времени старта (в модели плана нет фиксированного часа
  начала) — это готовая точка расширения, если понадобится.
